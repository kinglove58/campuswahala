# ADR 004: Explicit fixtures and server authority

Status: Accepted. The brief is not verified campus research. Label invented map geometry, programme catalogue/durations and schedules as unverified fixtures everywhere. No geographic or official claims. Guest avatar movement is local visual state only; no reward or leaderboard endpoint exists. Future game commands are server-authoritative, deterministic and transactional; offline cannot mint assets. PWA implementation is deferred until safe cache/conflict rules are implemented.
