# Product and scope

CampusWahala is one persistent university world, spanning entry through graduation and alumni memories. Initial campus identifiers are futa, oau and unilag. Adding campuses supplies validated packs rather than duplicated logic.

Three loops drive design: immediate situation → decision → movement → activity → consequence; daily schedule → classes/food/friends/hustle/study/rest; long term registration → assessment → results/progression → SIWES/project → signing out → alumni. All levels are supported; programme level structures and individual duration overrides are data.

Phase 0 only creates a temporary guest, enters a stylized fixture world and opens a phone. No academic scoring, commerce or social network is promised. Public pages describe future features as planned. Privacy is default; no free-text player chat in V1. Under-18 participation requires explicit age-appropriate product policies before social or monetary launch.

Success for this slice: users can select any launch campus, a fixture programme, level, adjusted duration and avatar; submit to API; resume safely; move and interact on desktop/mobile; see phone apps without leaving world. API failure must remain recoverable.
