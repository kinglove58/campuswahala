## Editing and reproducibility

Authoring entry point: [master.mjs](master.mjs). It contains original geometry, material gradients, semantic layers and explicit foot/knee/toe/arm poses. Four exported SVG facings per option have 13 named Inkscape-compatible groups; edit paths, gradients or strokes directly in vector tools, or edit the module to reproduce the entire gait. Each ORA has four facing groups containing 52 independently named semantic part layers, not whole-frame sprite layers. ORA raster parts are a companion for Krita/GIMP; editing a raster layer does not automatically update the vector rig or all walking frames. Round-trip changes must be reconciled into source before re-export.

From the repository root with existing pinned dependencies:

```sh
node scripts/art/export-m1-treatments.mjs --stills
# Inspect two masters FIRST; no atlases/variations generated by --stills.
node scripts/art/export-m1-treatments.mjs
python scripts/art/pack-m1-treatments.py
node scripts/art/verify-m1-treatments.mjs
node scripts/art/capture-m1-treatments.mjs
node scripts/art/compare-m1-treatments.mjs
```

The full command exports only the two representative masters, not Appearance/NPC variants. Node 22/24, Python 3, existing pinned Sharp, compiled game-engine package, existing esbuild and Playwright Chromium are used; no new dependency. Generated manifests hash LF-normalized source, atlas bytes and each shadow-free body pose. Verification rerenders source through the same alpha-compositing packing step and compares exact committed cell pixels, confirms 80 distinct body poses, no clipped anatomy, phase plant travel and real ORA layer bytes. This checks technical integrity, not attractiveness or physically perfect foot locking.

Walking runs at 8 FPS with alternating contacts, support travel, swing lift, knee bend, heel/toe rotation, opposite arm travel and subpixel torso recoil. Core shadow stays at (64,177), contact shadows diminish for lifted feet. The lab-only WorldEngine clock is paced to 64 source units/cycle laterally or 30.72 front/back. Discrete eight-frame animation means planted-foot drift between frames remains a visual review item; no continuous inverse kinematics claim. Production remains 230 world units/s. Actual Phaser captures prove all eight different moving poses per direction, not a naturalness score.

Proof render target is 30 FPS, gait 8 FPS, DPR1 software Chromium; actual body height about 73.1px / 10% of the 731px canvas at camera zoom .88. No physical-device performance claim. One 1024x960 atlas loaded per option (3,932,160 decoded RGBA bytes); encoded bytes and hashes in each manifest.
